MARVIS 复刻工具包 · HTML 版

浏览器直接可用的工具页

图片格式互转在浏览器本地完成 · 文件不上传服务器 · 已同步发布 GitHub

📦 两个复刻项目

bluetooth-link

github.com/laihainb666/bluetooth-link

无网络蓝牙离线通讯：纯 Python 标准库，Linux RFCOMM 点对点直连，文本 + 文件传输。借鉴 Kabootar / Chat-app-using-Bluetooth / PhoneLink 思路。

使用：python3 bluetooth_link.py server / client <对方MAC>

mouse-format-lite

github.com/laihainb666/mouse-format-lite

离线文件格式转换：图片 / 文本 / 电子书 / Office / PDF / 音视频 / ZIP 互转，CLI + WebUI，格式覆盖尽量对齐飞鼠格式。借鉴 flyingmouse-format（飞鼠格式）思路，内嵌 imageio-ffmpeg 无需系统 FFmpeg。

使用：python3 convert.py a.png --to jpg 或 python3 webui.py

🖼️ 网页版图片格式互转（纯前端）

拖拽图片到这里，或点击选择文件
支持 png / jpg / webp / gif / bmp，可多选
等待选择图片…

说明：转换完全在浏览器本地完成（Canvas API），图片不会上传到任何服务器；PNG/BMP 为无损格式，质量参数仅对 JPG/WEBP 生效。

⚙️ 完整运作原理

  • bluetooth-link：socket.AF_BLUETOOTH + BTPROTO_RFCOMM 建立 RFCOMM 通道 → 自定义帧协议（魔数 BL + 版本 + 类型 + 长度头）→ 文本 UTF-8 即时收发 / 文件按帧传输 → 接收端自动存入 received/。
  • mouse-format-lite：Pillow 处理图片、PyMuPDF 处理 PDF、imageio-ffmpeg 内嵌 FFmpeg 处理音视频、python-docx/openpyxl 处理 Office；CLI 与 WebUI（http.server + multipart 解析）共用同一转换核心。
  • 本页转换：FileReader 读入 → Image 解码 → canvas.toBlob(mime, quality) 编码 → URL.createObjectURL 预览并下载，全程零上传。
