📦 复刻项目（HTML 版 + Shell 版双版本）

mouse-format-lite（HTML 版）

github.com/laihainb666/mouse-format-lite

离线万能格式转换：图片 / 文本 / 电子书 / Office / PDF / 音视频 / ZIP 互转，本页即其网页版前端，图片本地零上传、其余格式走云端转换服务。借鉴 flyingmouse-format（飞鼠格式）思路。

使用：python3 convert.py a.png --to jpg 或 python3 webui.py

mouse-format.sh（Shell 版）

github.com/laihainb666/marvis-tools-html

与 HTML 版同能力的命令行版本：ffmpeg 直转图片/音视频，自动定位系统 ffmpeg 或 imageio-ffmpeg 内置静态二进制；文档 / PDF / 电子书 / ZIP 由 Python 核心兜底，另带 web 与 doctor 子命令。

使用：./mouse-format.sh a.png --to webp 或 ./mouse-format.sh web

bluetooth-link + encrypt-chat

github.com/laihainb666/bluetooth-link

无网络蓝牙离线通讯（RFCOMM 点对点），并附带加密通道对话 encrypt_chat：有网络走 TCP 在线加密通道、无网络走蓝牙离线加密通道，口令经 scrypt 派生密钥、每条消息 AES-GCM 加密防窃听篡改。

使用：python3 encrypt_chat.py listen --key 口令 / chat --host IP --key 口令

工具包总览

github.com/laihainb666/marvis-tools-html

本页 + mouse-format.sh + 加密通道对话（encrypt_chat.py）均发布在 marvis-tools-html 仓库；bluetooth-link 仓库同步收录 encrypt_chat.py。全部离线可用，不依赖第三方在线服务。

下载：marvis-tools-html

⚙️ 完整运作原理

  • bluetooth-link：socket.AF_BLUETOOTH + BTPROTO_RFCOMM 建立 RFCOMM 通道 → 自定义帧协议（魔数 BL + 版本 + 类型 + 长度头）→ 文本 UTF-8 即时收发 / 文件按帧传输 → 接收端自动存入 received/。
  • mouse-format-lite：Pillow 处理图片、PyMuPDF 处理 PDF、imageio-ffmpeg 内嵌 FFmpeg 处理音视频、python-docx/openpyxl 处理 Office；CLI 与 WebUI（http.server + multipart 解析）共用同一转换核心。
  • 本页转换：图片类走 FileReader → Image → canvas.toBlob 本地编码，全程零上传；其他格式走云端转换服务 POST /convert，结果通过 /download 链接下载。
